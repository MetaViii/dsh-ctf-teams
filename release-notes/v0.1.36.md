# v0.1.36 — Docker 默认解题环境

- 默认在独立 Docker 容器执行解题命令；`execution.backend: native` 保留本机／WSL 高级选项。没有可用 Docker 时明确报错，不自动退回宿主 shell。
- 新增 `ctf_teams_runtime` 与 `ctf_teams_exec`，支持镜像准备、附件导入、持久工作目录、后台作业、退出码、完整日志及有界输出。成员执行绑定当前任务尝试。
- 面板暂停、归档、成员移除、重派和路由修复联动容器作业。暂停保留成果，继续不重放旧命令。只读权限拒绝执行；自动审批仍走宿主工具策略，不修改用户权限或模型路由。
- 默认环境检查与图像助手使用同一容器。镜像覆盖常见 Web、密码、二进制、取证、图像和媒体工具；历史需求审查仅使用本机记录，真实题目、答案和凭据不进入镜像。

完整实现、工具清单、验收和已知边界见[本轮记录](../docs/docker-runtime-2026-10-28/README.md)。本轮不发布 npm 或公共镜像；首次使用可从包内 Dockerfile 构建。
