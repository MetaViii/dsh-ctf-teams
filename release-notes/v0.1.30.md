# v0.1.30 — 明确运行时，保留有效数据，减少升级中断

本轮合并此前已在本机验证的修复，并补齐 WSL 检查与安全缓存输出。版本号标识 Git 源码与候选包；本次没有向 npm 发布。

- `ctf_teams_env` 新增 `runtime=local|wsl` 与明确发行版选择。结果标明宿主、探测平台、Python、Linux 搜索路径；超时、解释器不可用、查找器失败标为 `unknown`。WSL 启动失败不会被当成工具缺失，不自动选择或安装发行版。
- WSL 检查使用 Linux 系统及用户 bin 范围，串行调用 launcher；兼容其 UTF-16LE 输出。自定义环境仍需独立验证，真实 WSL 调用超时不会被声称已修复。
- CTF2 CLI 新增 `--output file.json`，先校验响应再原子写入无 BOM 的 UTF-8 JSON。限流、协议错误和分页不完整保留旧文件；不使用隐式重试。补齐 `RATE_LIMIT_EXCEEDED` 别名的失败传播。
- 汇入此前本地完成的完成/暂停后重复唤醒修复、Windows PowerShell 模块路径兼容、审批清理补丁、模型路由诊断、preflight 修订和 CTF2 错误传播。
- 宿主准入与精确测试矩阵分离，允许后续 `0.2.x` 加载，保留运行时 API 适配和 `0.3.x` 上界。审查器实现变化时使用官方逻辑，保留原有审批行为。

验证证据与未覆盖项见 [第六轮迭代记录](../docs/ctf2-iteration6-2026-10-18/README.md)。更新实际桌面安装仍需在保存工作、退出宿主之后进行；Git 推送不等于 npm 发布或本机自动升级。
