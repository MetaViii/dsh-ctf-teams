# v0.1.33 — 解题历史检索与单条证据复核

- 新增只读 `ctf_teams_search`：检索当前队内 finding、任务结果和检查点、假设、实验方法与观察。先返回短摘要，再按绑定队伍代际的引用分页展开；正文分页保留 Unicode，内容哈希可识别变化。
- 解题面板支持证据搜索、状态/类型筛选、每页 10 条和详情展开，显示依赖、取代与历次核验。已失效或已取代的旧 confirmed 不再显示为绿色确认状态。
- 队长可显式请求单条复核或保存交接，服务端核对身份和记录。每次点击发送一条有界请求，保持战队当前暂停/运行状态；浏览、筛选、翻页不产生模型请求。
- 队长交接卡显示保存版本、状态是否变化、报告判断、争议与下一步。成员和旁观者的快照不包含交接笔记。

设计参考及未采用部分见 [ARTEX 研究](../docs/artex-study-2026-10-23.md)。本轮独立实现，未复制其代码或提示词；检索范围为已记录过程，未包含原始会话轨迹。

验证与交付见[第九轮记录](../docs/ctf2-iteration9-2026-10-23/README.md)。本次版本不代表 npm 已发布。
