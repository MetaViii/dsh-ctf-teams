# v0.1.37 — 面向难题的实验选择与停损

- 新增 `ctf_teams_experiment`：记录明确的正反观察条件、竞争假设、覆盖标识、估算成本和执行预算；按公开的成本分档规则提供短名单，不声称预测成功率。
- Docker 命令绑定实验后，在原有团队／任务授权下限制启动次数，并将命令超时压到剩余实验时间；省略或更换引用不能绕过当前路线的复核边界。
- 有效、基础设施故障和无效实验分别记录；队长引用具体试验复核反证，连续有效但无结论的实验要求重新审视假设。保留失败历史、文件和检查点，不自动把任务或题目标为失败。
- 暂停冻结实验时钟；重派后的旧尝试不能执行，队长可附理由显式重绑、续做或释放路线。旧战队数据兼容，未使用实验计划的旧命令保持原行为。
- 复用已验收的 `dsh-ctf-tools:0.1.36` 工具箱，不要求重建 8 GB 镜像。原生高级环境不承诺 Docker 实验预算。

实施、真实容器／宿主验证和边界见[本轮记录](../docs/research-control-2026-10-30/README.md)。不升级 DSH，不发布 npm，不恢复既有暂停战队。
