# v0.1.25 — the live dashboard tab

The plugin gains a **browser half**: a `解题面板` tab that sits next to
对话 / 轨迹 and shows the solve in real time, so watching a team no longer means
scrolling the transcript.

## What changed

- **`src/client/entry.js` + `lib/client.js`** — a `conversation.view` list-slot
  contributor. The tab renders the challenge header, a task progress bar,
  member lanes with live activity / unseen-board / unread-mail badges, the
  finding feed, the flag board and the host-computed `Next` line.
- **`src/dashboard-route.ts` + `src/dashboard-snapshot.ts`** — the read-only
  `GET /plugins/dsh-ctf-teams/state` route the tab polls (1.5 s, in-flight
  guard, paused while the page is hidden). It reads the durable team files —
  the same truth source as `ctf_teams_status` — and reuses `nextStepHint()`, so
  the tab and the transcript can never disagree.
- **`src/web-routes.ts`** — the Connection trust fence around that route: the
  raw `webServer` service sits outside browser authentication, so an
  unauthenticated request is refused (401/403/503) instead of leaking challenge
  state.
- **`scripts/build-client.mjs`** — the whole client build. The entry is written
  in the harness ModuleLoader dialect (`require` / `exports`, no JSX), so the
  envelope is a wrap: no bundler, no new dependency, byte-stable for `--check`.
- **Gates** — `verify:client` (bundle matches source + headless render smoke
  test) and `verify:dashboard` (route registration, payload assembly, bystander
  scoping, method whitelist, fence behaviour) joined `pnpm verify`; the old
  "client bundle removed from exports" assertions became positive ones.

## Verified on a real host

A scratch profile (base + web-app + this plugin, Harness 0.2.0-rc.2) was booted
and checked end to end:

- the client boot graph lists the row —
  `{"id":"@nanmicoder/dsh-ctf-teams","url":"plugins/??…/client.js&rev=…","inject":["@deepseek-ai/dsh-client-ui-conversation"]}`;
- `GET /plugins/dsh-ctf-teams/state` with the browser session answers
  `200`, `application/json`, `cache-control: no-store`, with the full team
  payload (challenge, members, tasks, findings, flags, `nextStep`);
- the same request without browser authentication answers `401`.

## Upgrade

Reinstall into the profile and restart the Host / Desktop app — both the client
bundle and the preset layer are read when the composition loads.

```bash
dsh plugin --profile <name> add @nanmicoder/dsh-ctf-teams
```

The tab only appears once a session exists (the shell hides the whole view ring
for a blank session); an empty workspace renders an invitation to start a team.
