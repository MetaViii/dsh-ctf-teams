# v0.1.32 — 证据能失效，交接能核对，增援有上限

- `report_finding` 支持观察、解释和决策类型、题目身份及依赖引用。新增只读 `ctf_teams_evidence` 分页查询，引用绑定团队代际。
- 前提被 refuted/inconclusive 或被独立更正取代时，依赖结论级联标为待复核；旧原文和裁决不删除。前提恢复不会自动确认派生结论。离线 preflight 不再接受失效证据，相同裁决重试不产生新进度。
- 新增队长 `ctf_teams_checkpoint`：运行状态与模型笔记分开保存，状态摘要与版本共同防止过期写入；保存历史、文件快照和未提交候选引用。读取、重复保存不唤醒队员，也不恢复或接管旧任务。
- `max_parallel_lanes` 可配置每题并行任务数，等待容量的任务沿原事件驱动调度；原任务结束后释放容量。不抢占正在执行的任务，0 清除限制。
- 状态给出实验报告、下一项反证与待复核信号，协议要求增援前检验关键假设。没有新增周期轮询、自动选模型或自动加人；token/墙钟硬预算与跨会话所有权转移仍待实现。

验证、安装和未覆盖范围见 [第八轮迭代](../docs/ctf2-iteration8-2026-10-23/README.md)。本次版本不等于 npm 已发布。
